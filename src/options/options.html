Configurações

1. Autenticação Google (OAuth 2.0)

Crie um ID do cliente OAuth do tipo Aplicativo da Web no Google Cloud Console e cadastre este URI de redirecionamento autorizado:

Permissão solicitada: https://www.googleapis.com/auth/spreadsheets (somente planilhas). O token de acesso fica apenas na memória do navegador e nunca é salvo em disco.

2. Planilha de destino

Lê os cabeçalhos da aba e cria um campo para cada coluna, mantendo os mapeamentos já existentes.

3. Mapeamento de campos

Para cada coluna da planilha, escolha de onde vem o valor. Em "Seletor CSS", informe um seletor por linha: o primeiro que encontrar texto é usado. Deixe "Atributo" vazio para ler o texto do elemento (ou use, por exemplo, href, content). Colunas da planilha que não estiverem mapeadas não são alteradas.

Coluna na planilha Origem Seletor CSS / valor Atributo

Antes de enviar, a extensão lê esta coluna na planilha e ignora registros cujo valor já existe. URLs são comparadas sem protocolo, "www.", parâmetros e barra final.

4. Compartilhar configurações

Exporte para um arquivo o Client ID, a planilha, a aba e todo o mapeamento (com os seletores) e importe em outro navegador ou computador. O arquivo não contém senhas nem tokens de acesso.
